## 四条 Contribution（可辩护性降序）

1. **相似度与年龄都看不见腐坏，接地残差看得见** —— 且它在**条目被检索出来之前**就能算，而策略侧 UQ 只在**执行开始之后**才有定义。
2. **规模 × 漂移的交互** —— 场景不变时单调饱和（复现 R-t-S `61.0→71.2`、ReCAP `9.0→31.5`），跨场次时不再单调。**把最强前作的曲线变成本文模型的特例。**
3. **抽象式提升算子（L1→L2）** —— 全库现有三种提升是逐字拷贝 / 同层去冗余 / 抽象到文本，**没有一种抽象到动作**。且它留在库内、不进权重。
4. **五项归因**（write / redundancy / staleness / interference / capacity），**其中三项在文献里已有独立佐证**。

| **G-0** | 语料是否记录了**采集场次与日期** | **单点故障。没有时间真值就不启动。** |
| **G-A** | 逐场次拟合门任务的铰链螺旋轴，看漂移量 vs 任务容差 | 无自然漂移 → 全部改 staged drift |
| **G-B** | `{单场次库, 跨场次库} × N ∈ {10²…N_max}` 的 precision@k，**看交互项** | 交互不显著 → 砍规模腿，转纯腐坏论文 |

## 三条必须提前拆掉的红线

1. **命名撞车**：`self-evolving` / `consolidation`（RoboHarness 摘要）、`cross-task procedural memory`（VLA-Pro 标题）、`lifelong robot learning`（LIBERO 副标题）—— **全部禁用**。

## ▶ 下一步：G-0 审计清单

G-0 只回答一个问题：**存量语料里，"这条 episode 是什么时候、在哪一个采集场次采的"有没有真值？**
没有它，本文整条时间轴不存在，idea 2 不应启动。按可靠性降序查四条：

| # | 真值来源 | 怎么查 | 可靠性 |
|---|---|---|---|
| 1 | 采集时显式记录的 **session id / 日期字段** | 查 episode 元数据 / manifest / 目录命名规约 | 最高 |
| 2 | 文件系统 **mtime / ctime** | `stat` 抽样，看是否成簇 | 中（**拷贝会失真，必须与 #4 交叉验证**） |
| 3 | 图像 **EXIF / 光照统计**聚类 | 对每条 episode 的首帧算光照直方图，看是否分离成簇 | 中 |
| 4 | **从铰链轴拟合结果反推场次分界** | 逐 episode 拟合门任务的螺旋轴，看轴参数是否分层成簇 | **最强——因为它直接就是被测量本身**（= G-A 的副产品） |

> **#4 是最优路径**：它同时回答"有没有时间真值"和"有没有自然漂移"两个问题，且它的产物**同时交付 idea 1 的 §10 待办第 3 条**（追溯铰链标定）。
